# Grave Error — design options

Three teaser/placeholder directions for graveerrorgame.com. Each is a standalone HTML
file — double-click to open, or browse them all in the preview gallery (see the master
`design-preview/` folder in the workspace root).

- **Option A — Rot** (`option-a-rot.html`): gritty horror. Decay/blood-red on near-black,
  grungy grain texture, oppressive mood. The most overtly "zombie horror" of the three.
- **Option B — Requiem** (`option-b-requiem.html`): atmospheric minimal. Drifting fog, a
  faint headstone icon, sparse serif type, and a subtle countdown. Quiet, dread-filled,
  elegant.
- **Option C — Signal** (`option-c-signal.html`): retro / VHS glitch. CRT scanlines,
  chromatic-aberration "ERROR" glitch text, terminal typography. Plays up the "error" /
  system-failure side of the name.

All three include: the GRAVE ERROR wordmark, a "coming soon" status, a teasing one-liner,
an email notify form (demo only — shows a thank-you, no backend), a "Wishlist on Steam"
placeholder button, an "An Atheos Studios game" credit link to atheosstudios.com, and
social placeholders. Copy is placeholder — tweak freely once a direction is chosen.
